# Para Homónimo

Una referencia de homónimos en español (A Spanish homonyms reference).

## ¿Qué son los homónimos?

Los homónimos son palabras que se escriben o pronuncian igual pero tienen significados diferentes.

## Ejemplos

| Palabra | Significado 1 | Otros Significados |
|---------|---------------|-------------------|
| banco | Asiento largo para varias personas | Institución financiera, Conjunto de peces |
| vino | Bebida alcohólica hecha de uvas | Forma pasada del verbo 'venir' |
| cola | Parte del cuerpo de algunos animales | Pegamento, Fila de personas esperando |
| capital | Ciudad principal de un país o región | Dinero o recursos económicos |
| hoja | Parte de una planta | Lámina de papel, Parte cortante de un cuchillo |

## Uso

Este repositorio contiene una lista de homónimos comunes en español para referencia educativa.
